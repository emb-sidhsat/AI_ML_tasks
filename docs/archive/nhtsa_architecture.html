03 Criticality Scoring — 3 NLP Layers Progressively richer text representations
Layer 1
Rule-Based
Tiered safety keyword matching (crash / fire / stall / rollaway)
Structured signal flags: crash, fire, injury, fatality
Component risk scoring — steering, brakes, airbag, fuel weighted by danger tier
Incident-to-filing date lag as urgency proxy
TF-IDF (unigrams + bigrams) for statistical text representation
Layer 2
Classical ML
Silver labels from structured flags (weak supervision)
Naive Bayes → Logistic Regression → LinearSVC complexity ladder
5-fold stratified cross-validation scored by F1
Best model outputs ml_prob criticality score
Feature weight inspection for interpretability
Layer 3
Semantic NLP
SBERT all-MiniLM-L6-v2 — 384-dim sentence embeddings
UMAP reduction to 2D (cosine metric, n_neighbors=15)
HDBSCAN density clustering — discovers defect mode groups without a preset k
Semantic similarity lookup for "have we seen this before?"
Zero-shot classification via facebook/bart-large-mnli
↳ composite_score (0–100) Weighted combination of keyword score, ML probability, component risk, structured flags, and SBERT cluster depth.
